# Асістент — локальний AI-асистент викладача

Десктопний застосунок: викладач завантажує підручники, методичні розробки та наукові
матеріали, система їх парсить і будує локальну базу знань, а далі відповідає на запитання
**виключно за цими матеріалами**, поєднуючи кілька джерел і посилаючись на конкретні сторінки.

Усе працює **на комп'ютері викладача**. Жодного хмарного AI. Матеріали не залишають машину —
і це не обіцянка в README, а `app/net_guard.py` плюс тест, що валить збірку при спробі
вихідного з'єднання.

НДР «Асістент», Інститут ракетних військ і артилерії НАСВ, Львів.

---

## Швидкий старт (режим розробки, без жодної моделі)

```bash
# 1. Бекенд
cd backend
python3.12 -m venv .venv && .venv/bin/pip install -e ".[dev]"
ASISTENT_STUB=1 .venv/bin/python -m uvicorn app.main:app --port 8765

# 2. Фронтенд (в іншому терміналі)
cd frontend && npm install && npm run dev
```

Відкрити http://127.0.0.1:5173 — Vite сам проксює `/api` на 8765.

`ASISTENT_STUB=1` вмикає детерміновані заглушки замість моделей: псевдовектори з хешу,
ехо-реранкер і LLM, що будує відповідь із поданих фрагментів. Увесь інтерфейс і всі
952 тести працюють без жодного завантаженого ML-файлу.

## Запуск із реальними моделями

1. Встановити [LM Studio](https://lmstudio.ai), відкрити його один раз, увімкнути сервер
   (порт 1234).
2. Завантажити мовну модель. Для української рекомендовано
   **MamayLM-Gemma-3-12B-IT-v2.0, Q4_K_M** (7.3 ГБ): найвищий виміряний показник української
   серед моделей до 26B (UkrQualBench ELO 1503.1). Поміщається у 8–12 ГБ VRAM і в 16 ГБ
   unified memory на Apple Silicon.
3. Завантажити ML-моделі приймання й пошуку:
   ```bash
   python scripts/fetch_models.py --out ~/.asistent/models
   python scripts/verify_models.py ~/.asistent/models
   ```
4. Запустити без `ASISTENT_STUB`.

**Не варто:** `gpt-oss-20b` — 12.1 ГБ і ELO 1304.6; на 16 ГБ Mac гардрейл LM Studio його
не пропустить, і українською він помітно слабший.

## Десктопна збірка

```bash
python scripts/build_runtime.py          # релокований Python через uv + python-build-standalone
cd src-tauri && cargo tauri build        # → .exe (NSIS, perUser) / .app + .dmg
```

Windows-збірку можна зробити лише на Windows, macOS — лише на macOS: Tauri не підтримує
крос-компіляцію. Матриця в `.github/workflows/release.yml` це вже робить.

## Тести

```bash
cd backend  && .venv/bin/python -m pytest tests/ -q   # 843
cd frontend && npm test -- --run                      # 109
```

## Структура

| Каталог | Що це |
|---|---|
| `backend/app/ingestion/` | Docling-конвеєр, український OCR, тріаж сторінок, чанкування |
| `backend/app/embeddings/`, `rerank/` | ONNX Runtime, без torch у гарячому шляху |
| `backend/app/retrieval/` | USearch + FTS5 + RRF, диверсифікація джерел, утримання |
| `backend/app/backends/`, `generation/` | LM Studio, промпти, цитати |
| `backend/app/api/`, `jobs/` | HTTP API, SSE, черга з посторінковим відновленням |
| `backend/app/eval/`, `scripts/` | Recall@k, MRR, nDCG, OCR-бейк-оф — для звіту з НДР |
| `frontend/` | React + Vite, PDF.js із підсвіткою цитованого фрагмента |
| `src-tauri/` | Оболонка: вікно, діалоги, життєвий цикл sidecar. І більше нічого |

## Резервна копія

Копіювати `assistant.db` **лише після коректного завершення застосунку** — на
виході виконується `PRAGMA wal_checkpoint(TRUNCATE)`, і всі дані переливаються
в основний файл. Якщо застосунок працює, копіюйте разом із ним `assistant.db-wal`
і `assistant.db-shm`, інакше копія буде неповною.

Самі документи лежать окремо, у `docs/` під UUID; оригінальні назви — метадані
в базі.

## Три речі, які легко зламати, не помітивши

1. **`OcrAutoOptions` у Docling.** Дефолт резолвиться в **китайські** моделі на Windows і у
   французьку/німецьку/іспанську/англійську на macOS. Української немає в жодному.
   Завжди задавати OCR явно.
2. **`HeadingHierarchyOptions(enabled=True)` + `generate_parsed_pages=True`.** Без першого
   кожен заголовок PDF отримує `level=1`, ієрархія стає пласкою і `header_path` — беззмістовним.
   Без другого `use_style` тихо не працює.
3. **Екранування у FTS5.** Кожен термін іде через `'"' + t.replace('"','""') + '"'`.
   Голий `Д-30` парситься як оператор NOT.
